## 🚀 How to Run & Play

### Prerequisites
To run the game, make sure you have **Java 21 (JDK)** installed on your system. 
If you don't have it or need help installing it:
* **Windows:** [Watch this YouTube tutorial](https://www.youtube.com/watch?v=CUxpqVRJI8o) or download directly from [Adoptium](https://adoptium.net/).
* **MacOS:** [Install Homebrew](https://brew.sh/), then run this command in your terminal: `brew install --cask temurin@21`
* **Linux:** Run these commands in your terminal: 
  `sudo apt update && sudo apt install openjdk-21-jdk -y`

### How to Execute
You can easily run the game without compiling the code:
1. Go to the **Releases** section on the right side of this repository.
2. Download the latest `.jar` file.
3. **To launch:** Double-click the `.jar` file. 
   * *If it doesn't open or acts like an archive, open your terminal in the file's folder and run:* `java -jar [filename].jar`

### Gameplay Instructions
Once the game is launched:
1. Click **"Create the server"**.
2. Click **"Connect to server"**.
   * *(Note: If you click "Connect" without creating a server first, the game will freeze for 5–7 seconds while searching for a local server. This is normal behavior!)*
4. Enter your nickname on the screen and start the game!

> 💡 **Note for Single Players:** You can easily launch the game alone. In single-player mode, it works as a sandbox simulator where you can test the mechanics and try to maximize your budget without waiting for a second player.

### Additional Information
You can find all the information about the technologies used, architecture, and the rules of the game inside the `description` folder of this repository.
